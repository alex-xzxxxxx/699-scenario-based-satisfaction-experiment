# Application under test

Not written by hand. V0 is generated by the implementation model in Week 3 from
`app/REQUIREMENTS.md` **and nothing else**.

| Version | Built  | Contents                                   |
|---------|--------|--------------------------------------------|
| V0      | Week 3 | Generated from the requirements document   |
| V1–V3   | Week 5–6 | Copies of V0 with documented seeded defects |

Stack: Node/Express + plain HTML/JS, server-side sessions (decision D-002).

Five use cases: registration; login/logout and session handling; creating and
editing tasks; listing and searching tasks; access control (a user must not see
or change another user's tasks).

Each version is tagged in git. V1–V3 are copies of the **tagged** V0, so the
stack cannot change after M2.
